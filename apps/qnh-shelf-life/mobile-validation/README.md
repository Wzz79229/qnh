# 库管 Android 0.4.0

当前功能为库位标签；保质期管理暂停。保持原 applicationId 和稳定签名，可覆盖安装 0.2.0 / 0.3.0。

## 启动与登录

启动先显示牵牛花官方登录页面，只有确认进入牵牛花且读取到一致租户身份后才能进入库管。已有有效登录时自动核验后进入，无须重复填写密码。没有“跳过登录”或手动勾选授权入口。

登录成功立即隐藏牵牛花页面，首页、商品搜索、门店选择和结果列表使用原生界面。官方 WebView 在手机内部维持会话并执行库存查询，不使用 Cloudflare 云端浏览器，不读取或上传密码和 Cookie。牵牛花官方多因素验证仍由用户亲自完成。

认证状态只在进程内存在，不接受 Intent 或本地偏好设置中的登录标记；应用退出前台、进程重启、登录失效、租户变化或网络页面错误会锁住功能并要求重新核验。返回编辑页时若租户已切换，会清空之前的商品和预览。账号切换按钮清除本 App 官方 WebView 的网站登录数据，然后重新显示官方登录页面。

## 查询商品和库位

- 商品名称：输入至少两个字符后自动查询，支持下拉选择；也可点击“查询”查看本页结果。
- 支持完整 SKU、库位编码、商品条码、外部编码等条件组合查询。
- 库位与牵牛花相同，最多四段，每段最多六个字符；可用 C55、C55-3 等前缀筛选。
- 门店 / 仓使用原生层级选择列表，映射当前官方页面可见的选项；提供上一级和更多选项，不固定租户或门店。
- 支持结果翻页，同一商品不同库位分别选择。
- 全部商品数据来自“库存查询（新）→商品库存”，不使用商品主档或预存商品库。

页面的商品条码不能当成 SKU。选中库存记录后，会通过该行“查询流水”打开的官方库存流水头部，核对完整 SKU、商品名称及门店，与 URL 的 SKU 筛选一致才带回标签。名称和库位查询未完成 SKU 核对前，不会生成猜测的编号。

每次查询核对输入条件、官方 URL 回执及表格刷新；输入变化、分页变化、登录或租户变化均使旧结果失效。名称和编号始终保留字符串精度及前导零。

## 标签图片

80×60 毫米、945×709 像素、300 DPI PNG，纯黑白。参考项目内“库位打印”的 label.js：名称居中，空规格仍保留“规格：”；SKU 文字后六位，Code128 编码完整 SKU，底部大字库位。

在标签页核对商品名称、规格、SKU 和单个库位后生成图片。支持保存 PNG、系统分享发送给标签打印软件、系统打印。修改内容必须重新生成。标签只在手机生成，不自动上传业务数据或图片。登录核验和牵牛花查询需要联网；登录后的标签渲染不依赖云端。

## 图标与验证

深绿色仓库与条码图标，包含传统密度图、圆形图、Android 自适应图标及 Android 13 主题单色图标。

CI 执行运行时测试、登录门禁状态测试、Java 完整 SKU 编码解码、示例 PNG 解码、Android release 编译与 lint。手机上登录后隐藏页面、原生名称下拉、门店层级选择、保存分享和实际打印仍需实机确认。
