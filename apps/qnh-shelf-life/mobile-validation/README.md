# 库管 Android 0.7.0

当前启用库位标签，保质期功能暂停。保持原签名与 applicationId，可覆盖升级。

## 多选生成与相册保存

在单个输入框输入名称、SKU或库位，自动识别查询类型。商品数据只来自牵牛花“库存查询（新）”。名称、规格、SKU与库位均只读。

唯一结果自动生成一张标签。多条结果可以直接点选单张，或勾选多个商品与库位后点击“生成所选”；支持全选本页，每批手选最多50张。输入A10等库位首段后，还可点击“生成A10全部标签”，程序逐页获取并核对该区域的全部商品库位，排除A100等其他首段；区域生成最多500张、压缩图片总量最多16MiB，超过时提示按更细库位分批。翻页或修改查询会清除当前选择，避免混用不同查询结果。每条所选记录都会打开库存流水核对完整SKU；返回库存列表后按原查询URL、筛选条件、页码、租户和完整表格恢复受验证状态（含页面被重新创建的情况），再核对下一条。重新检查查询条件与表格，再核对下一条。结果发生变化、登录失效或租户切换时中止，不输出部分核对结果。

生成后通过“上一张 / 下一张”检查每个商品的只读资料与标签。“保存全部图片”一次将所有标签分别保存到手机相册“库管标签”目录，无ZIP、无长图。单张仍使用“保存图片”。批量分享使用多个独立PNG交给接收应用，接收应用是否支持多图由其自身决定。

每张标签为80×60毫米、945×709像素、300DPI。SKU文字显示后六位，Code128条码保留完整编码。保存原始PNG字节，避免相册保存时重新压缩。不同商品仅保留压缩PNG，预览只持有一张位图，批量生成不会同时保留多张完整位图。

保存/分享在后台线程执行，并阻止重复点击；相册批量保存失败或查询、租户改变时，回滚本次刚创建的图片，不删除已有相册图片。Android10及以上通过MediaStore保存自建图片；Android8/9仅在点击保存时请求旧版写入存储权限。参考：[Android共享媒体文档](https://developer.android.com/training/data-storage/shared/media)。

## PDF保存

点击“保存PDF”选择文件位置，当前所有标签合并成一个文件，一张标签一页。PDF每页精确80×60毫米，图片使用黑白无损压缩并关闭插值，保留完整SKU条码。导出在后台进行，不调用系统打印服务；返回文件选择器后，先确认原登录租户，再写入所选位置。

## 扫码与输入

查询框右侧提供“扫码”，首次点击按需请求相机权限。在本机使用Camera2和已有ZXing解码，不拍照存盘、不上传画面。连续两次识别一致后自动返回查询；Code128等编码作为SKU，EAN/UPC作为商品条码，库位编码自动识别为库位。完整标识符和前导零保留为文本。手工键入或粘贴的小写字母自动转为大写，中文与数字保持原样；扫码原始SKU保持实际大小写。

## 登录与界面

启动时在官方牵牛花页面登录。登录外框改为紧凑布局，减少顶部占位、扩大官方网页区域，提供加载进度、刷新与放大/缩小按钮；返回或旋转时优先复用当前官方页面，避免强制重新加载。业务界面中的WebView保持完全透明，不能抢焦点、接管触摸或移到前台；只有员工亲自点击重新登录才显示官方页面。按牵牛花登录租户隔离，查询改变、租户改变和重新登录都会使旧任务失效。

沿用0.6.1的新图标、居中查询框和按字体宽度排版的SKU文字。移除App内蓝牙打印、系统打印入口及蓝牙权限；保留保存相册与分享图片。

## 验证

脚本测试覆盖多选核对、19位SKU、旧表格、变更的查询条件、取消请求、租户切换。Java单元测试覆盖独立文件输出、相同SKU文件名不冲突、批量数量限制、字体与条码。

Android模拟器使用受控HTML页面，运行真实登录、查询、后台WebView、库位标签Activity。检查A10区域跨两页生成三张且不混入A100、多选两个商品、逐项完整SKU核对、切换预览、点击一次保存两张独立相册图片、逐字节一致、两张条码分别识别为不同SKU，以及保存取消后回滚；PDF按钮保存为两页PDF，经Android原生PDF渲染后逐页验证条码。继续检查隐藏网页像素不泄露、SSO不自动打开登录页、显式重新登录有效。

模拟器不使用真实牵牛花账号；实际账号网络及不同手机相册的展示效果仍需实机验收。

扫码验证包含原始19位编码和旋转帧解码、相机Y平面行/像素间隔、Camera2预览启动、返回扫码结果后自动查询，以及输入和粘贴自动大写。相机实物对焦和不同手机相册界面仍需实机体验。
