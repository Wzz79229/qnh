# 库管 Android 0.6.1

当前启用库位标签，保质期功能暂停。保持原签名和 applicationId，可覆盖升级。

本版修复部分系统字体导致 SKU 后六位文字被误判为无法排版、预览不显示的问题。文字按实际字体宽度选择字号，必要时分两行；完整 SKU 条码保持不变。查询输入文字和提示语居中，高度随字体调整。生成成功或失败均会更新明确状态。

## 查询和标签

启动时在官方牵牛花页面登录。进入业务界面后，后台 WebView 仍保持 VISIBLE 以运行页面，但 alpha 始终为0，不能抢焦点、接管触摸或移到前台。只有启动登录或亲自点击“重新登录牵牛花”才显示官方网页。即使发生整页SSO跳转或登录失效，业务 Activity 也只显示原生验证提示，不自动打开登录 Activity。

单个输入框自动判断名称、SKU、库位；识别有歧义可点击类型提示更改。查询按钮位于查询卡片底部。商品源为库存查询（新），不会查询商品主档。选中后通过库存流水核对完整SKU，名称、规格、SKU和库位只读；唯一结果自动选择，多条结果先选商品与库位，随后自动显示标签。

标签导出为80×60毫米、945×709像素、300DPI。条码保存完整SKU，文字显示后六位。租户改变、查询改变或明确重新登录时使旧任务失效；验证未完成时不能查询、导出或发起打印。

## 得力DL-720W(NEW)蓝牙打印

1. 先在手机系统蓝牙中配对打印机。
2. 查询生成标签后，点击“打印”→“得力720W（蓝牙直打）”。
3. 首次允许连接附近设备，选择已配对的打印机。
4. 核对80×60毫米标签纸、份数和纸张间隙（默认2毫米）；先打印1张。
5. 检查方向、出纸定位和条码能否扫码，再增加份数。

只读取已配对设备，不扫描周边设备，不请求定位权限，不需要Cloudflare或得力云账号。Android12及以后按需请求BLUETOOTH_CONNECT；老系统仅使用BLUETOOTH权限。保存选中的设备地址和标签间隙供下次使用。

实现使用经典蓝牙RFCOMM/SPP和TSPL BITMAP指令，传输在后台线程执行，有超时、停止发送及设备更换。仅连接失败且尚未发送数据时可尝试不带链路认证的RFCOMM连接；写入后不自动重试，以免重复出纸。失败或中止后应先检查打印机再重试。

按照型号手册的8点/毫米重新生成640×480黑白位图，条码模块为整数像素，不直接缩放300DPI图片。使用TSPL白位为1、黑位为0的点阵，支持1–20份和0–5毫米间隙；保留系统打印与分享。

**实体720W尚未连接验证。** 自动测试确认了打印数据和条码；SPP服务、固件兼容性、实际出纸及打印质量仍需实机试打。“已发送”只表示数据传输完成，不代表打印机已经出纸。

参考：[DL-720W(NEW)型号手册](https://tomro-res1-1316353155.cos.ap-guangzhou.myqcloud.com/common/90/b0b6cc6adb02f54a1681aaa4eaf041.pdf)（得力手册的经销商托管副本）、[TSC TSPL原厂指令手册](https://fs.tscprinters.com/en/dl/1/2541)、[Android蓝牙权限](https://developer.android.com/develop/connectivity/bluetooth/bt-permissions)、[Android BluetoothDevice](https://developer.android.com/reference/android/bluetooth/BluetoothDevice)。

## 验证

测试包含查询分类、回执、租户隔离、300DPI与720W点阵的完整SKU解码、TSPL字节边界、只读字段、release编译、lint和签名。

Android模拟器使用受控HTML页面跑真实登录Activity、后台WebView和库位标签Activity；查询、名称选取、库位查询使用requestAnimationFrame渲染，临时租户缺失后自动恢复。额外检查整页SSO跳转不会自动打开官方页面，只有亲自点登录才显示；把背景网页设置为高亮紫色并模拟提高层级，截图中不得出现网页像素。

受控页面不连接真实牵牛花账号，不能替代真实手机和打印机验收。PNG导出、系统打印、缓存与内存优化继续保留。
