# 库管 Android 0.5.0

当前仅启用库位标签，保质期功能暂停。保持原签名与 applicationId，支持覆盖升级。

## 使用

1. 启动后在手机上的牵牛花官方页面登录，验证成功后隐藏官方页面。
2. 进入库位标签，直接在页面顶部按名称、SKU、库位或更多条件查询；门店选择、结果分页均在原生界面完成。
3. 唯一库存记录自动选取；多条记录时通过名称下拉或结果卡片选择。完整 SKU 核实后自动生成图片，无须再次点击生成。
4. 商品名称、规格、完整 SKU、库位和门店来自查询结果，结果卡片均为只读；不再提供商品手填与示例填入。
5. 保存、分享或打印标签。未配置单一库位的记录不能出图，应先在牵牛花维护库位。

标签保持80×60毫米、945×709像素、300 DPI，完整SKU编码条码，文字显示后六位。长规格自动换行，查询条件变化立即清除旧标签，旧的后台生成任务不能覆盖新查询。

## 性能与内存

- 静态网页资源使用正常HTTP缓存，仍保持启动和返回前台的登录核验。
- 查询脚本压缩，按网页文档注入一次；后续调用短表达式，空闲时只检查登录身份。
- 登录与查询中快速检查，标签页空闲2.2秒、首页空闲10秒检查，减少无操作时轮询。
- 官方页面隐藏时停止自动加载商品图片，登录时恢复验证码等图片。
- 回到库存页优先复用历史路由和门店筛选；不重复打开独立查询 Activity。
- App退后台暂停网页计时器，后台停留60秒或出现低内存压力时释放网页，登录Cookie保留，下次仍需真实核验。
- 标签在后台线程生成，RGB565位图约1.34MB；逐行黑白处理只需945个整数的临时缓冲，打印时按需解码，不保留额外整张位图。
- 分享缓存超过24小时后清理；release启用代码与资源压缩，排除暂停功能的脚本。

这些优化未等同于某一手机的整机RAM降幅。牵牛花完整WebView仍是主要运行时开销，实际加载速度和进程内存需手机实测。

## 验证

CI运行登录门禁、查询回执、异步结果失效等测试，release编译与lint、条码解码、APK签名检查。另在Android模拟器验证实际PNG的完整SKU、纯黑白、300DPI、位图分配、结果字段只读，以及手机和宽屏原生界面截图。

模拟器仅使用debug源集的合成预览Activity，不访问牵牛花账号，也不会进入release APK。不得用此测试界面证明真实库存接口已经实机验证。

商品源仍为库存查询（新）。选中后使用该记录的官方库存流水核对完整SKU，不将UPC当SKU；不同租户、登录失效、前后台切换、取消或输入变化都会使旧查询失效。无手动勾选授权，无后台业务写入；不读取、上传密码或Cookie，不依赖Cloudflare云端浏览器。
