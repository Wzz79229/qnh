# 库管 Android 0.3.0

当前功能：库位标签图片生成。首页提供多个功能入口，保质期管理按用户要求暂停；旧源代码、本机已存批次和签名保留，不继续部署保质期的 D1/R2 配置。

## 标签规则

参考 Codex 自动化程序项目中的“库位打印”任务，实际规则来源是其 kuwei-label-maker 的 label.js。80×60 毫米、945×709 像素、300 DPI PNG，纯黑白无灰阶。

- 居中商品名称 11 pt，规格 15 pt；文字过长会排版或提示，不静默裁切。
- 规格去掉末尾完整的重量/容量换算组，保留颜色、尺码和包装规格。null、空等为空规格；空规格仍打印“规格：”并保留行高。
- SKU 文字仅显示后六位，Code128 条码编码完整 SKU，所有编号始终为字符串，保留前导零和长数字精度。
- SKU 条码区 52×8 毫米，保留两侧静区；底部大字库位初始 54 pt，过长时缩小，低于可读字号则拒绝。
- 修改任一字段后，旧预览、保存、分享和打印状态失效，必须重新生成。

## 使用

1. 打开“库管”→“库位标签”。填写商品名称、规格、完整 SKU 和一个库位；也可点击“从牵牛花库存查询（新）填入”。
2. 在 App 内牵牛花官方页面亲自登录，选择门店/仓，输入完整 SKU 查询。新入口只访问“库存查询（新）→商品库存”，不访问商品主档。
3. 选择本次查询返回的一条商品/库位记录，回到编辑页核对后生成标签图片。未设置库位或一个字段包含多个换行库位时，需先补全为一个库位。
4. 保存 PNG 到系统文件选择器指定位置，或使用系统分享发送给标签打印软件。系统打印入口按 80×60 毫米真实尺寸生成 PDF，实际打印需手机已有对应打印服务。
5. “填入示例”只用于查看样式，使用前替换成真实数据；示例使用合成商品和 SKU。

标签在手机生成，不需要 Cloudflare 或 GitHub 读写，不自动上传商品资料或图片。不需要相机、相册、存储权限。分享仅临时授权用户选中的目标读取该张图片；不同分享图片使用不同私有缓存文件。

## 库存查询确认规则

使用实际检查到的 #/co-wms/inventory-query-integration/list?tab=goodsBatch 页面及 skuIdListStr 查询框。商品行显示商品名称、规格、门店/仓和库位，不显示独立 SKU 字段，因此必须同时确认当前输入框、查询后新 _t 标记、官方 URL 的单一完整 SKU 筛选和表格刷新。不能根据 UPC 补造 SKU 或 SPU。失败、登录变化、租户变化、取消或输入变化时丢弃旧结果。同一 SKU 的不同库存行供员工明确选择。

这只是手机上的查询确认，不作为后台租户授权。本版不接云端业务写入。保质期、商品图片归档和 D1/R2 配置暂缓。

## 安装及验证

Android 8 及以上。应用名称变为“库管”，保留原 applicationId 和 0.2.0 稳定签名，可以覆盖安装 0.2.0，不清除旧本机数据。0.1.0 临时签名版仍需先卸载后安装。

CI 执行 JS 运行时测试、Java 条码编码/解码测试、示例 PNG 条码解码、Android release 编译与 lint。安卓手机库存页面交互、保存/分享/打印需实机验收；构建通过不代表完成实机验收。

构建：JDK17、SDK35、Gradle8.9，根目录 npm ci --ignore-scripts、node mobile-validation/build-runtime.mjs，再于本目录 gradle :app:testReleaseUnitTest :app:assembleRelease :app:lintRelease。稳定私钥仅在本机 .local/android-signing，禁止提交私钥或密码。
