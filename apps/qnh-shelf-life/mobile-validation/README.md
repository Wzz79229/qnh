# 鲜期 · Android 0.2.0

员工在手机 App 的官方牵牛花页面登录，登录成功进入鲜期。扫描 SKU 后即时查回商品名称、规格和主图，再拍摄生产日期、保质期，核对自动计算的到期日期，手动填写清点件数后保存。无需云端浏览器或店内电脑。

## 安装与实机验收

Android 8 及以上。0.1.0 临时签名验证版需先卸载再安装 0.2.0，重新登录牵牛花；0.1.0 没有批次存储。0.2.0 起由本机稳定密钥签名，今后使用同一签名覆盖升级。不得卸载或清除已有待同步批次的 App。

1. 登录牵牛花，扫描真实 SKU；核对查回的名称、规格、主图。
2. 分别拍清生产日期和保质期。识别有歧义时重新拍摄；不允许根据模糊日期直接保存。核对日期和计算结果，再填写件数。
3. 点击保存批次，先加密保存至当前租户的本机草稿；无云端连接时明确显示“本机待同步”。生产日期改变后重新拍摄并形成另一批次。
4. 点击“连接云端 / 同步批次”。数据库和存储未配置时不读取牵牛花会话。配置完成后，首次显示说明，由员工亲自同意才会临时将会话交给自己的 Cloudflare 后台核实租户。
5. 云端确认后同步本机待同步批次，查看最近 100 条云端批次及已归档主图。同 SKU、不同批次不覆盖；网络失败可重试，同一批次 ID 不重复增加。
6. 切换牵牛花租户或退出后，当前商品、日期、云端凭据和其他租户内容立即隐藏。新租户需重新连接云端。

构建和自动化测试不等同于手机实机验收。0.1.0 的登录与真实 SKU 查询已由用户确认成功；0.2.0 的相机、中文 OCR、服务端会话核实仍需实机验证。

## 数据边界

- 相机只用于扫描和日期识别；ML Kit 中文文字模型随 APK 打包，在手机处理。包装照片只在内存处理，不写文件、相册、数据库或上传。
- 草稿只保存商品快照、生产日期、保质期、计算到期日期、件数等字段；使用 Android Keystore AES-GCM 加密，按租户分组。
- GitHub 只用于当前源代码版本和 CI 构建、APK 分发；手机批次新接口使用 Cloudflare D1，商品主图副本使用私有 R2。没有全量商品库导入。
- 云端启用需员工同意：本机 QNH Cookie 仅通过 HTTPS 发往固定自有 Worker，再仅向 QNH 官方登录状态接口校验，不持久化、不记录、不交给图片域名。Worker 只保存自有随机会话令牌的摘要、经 QNH 核实的租户和过期时间；手机自有令牌仅在内存中保留。
- QNH 登录状态接口来自其公开官方网页脚本，并非开放平台接口承诺；接口变化或验证失败时拒绝云端访问，保留本机批次。服务端不信任手机填写的 tenantId。
- 商品图片只允许 HTTPS img.meituan.net，云端检查格式、限制 2 MB、拒绝重定向。R2 不启用公开访问，图片读取也需当前租户授权。
- WebView 不开放特权 JS 接口、文件访问、明文 HTTP、证书忽略或远程调试。

## 云端准备

按 backend/MOBILE-CLOUD.md 创建 D1 / 私有 R2 并绑定。未完成绑定时新接口明确拒绝写入，不会显示已保存云端。旧网页 GitHub 数据接口保留兼容，不参与 Android 新批次存储。

## 构建与签名

JDK 17、SDK 35 / Build Tools 34.0.0、Gradle 8.9、AGP 8.7.3。根目录 npm ci --ignore-scripts、node mobile-validation/build-runtime.mjs，再于本目录 gradle :app:assembleRelease :app:lintRelease。

GitHub workflow 仅 contents:read，构建 unsigned release，产物包含 APK 和官方 apksigner.jar；稳定私钥和密码只保留本机忽略目录 .local/android-signing，不提交仓库或 CI。使用官方 apksigner 在本机签名并 verify，分发带 SHA-256 的已签名 APK。签名私钥需要管理员自行妥善离线备份，丢失将无法覆盖升级。
