# 库管 Android

当前版本：[库管 0.4.0 APK](./kuguan-0.4.0.apk)，Android 8 及以上。

## 本版更新

- 新增深绿色“仓库＋条码”应用图标，适配圆形、自适应和 Android 13 主题图标。
- 启动先登录牵牛花；确认登录有效后才可进入库管。有效登录可自动核验，无需重复填写密码。
- 登录成功后牵牛花页面自动隐藏，后续查询使用 App 原生界面。
- 名称输入至少两个字符后自动查询并显示下拉选择，包含规格、门店及库位；也可点击查询查看结果。
- 支持 SKU、库位、商品条码和外部编码组合筛选，以及门店 / 仓选择、结果翻页。
- 查询来自“库存查询（新）”，不访问商品主档；选中记录后核对官方库存流水中的完整 SKU，不把商品条码当 SKU。
- 保质期管理继续暂停。

## 安装与使用

已有 0.2.0 / 0.3.0 可直接覆盖安装，保留本机数据。最早 0.1.0 验证版签名不同，需要先卸载后安装；已有待同步数据时不要卸载或清除应用数据。

1. 打开“库管”，在牵牛花官方页面亲自登录。
2. 验证成功后自动隐藏牵牛花，进入库管首页。
3. 进入“库位标签”→“从牵牛花库存查询（新）填入”，选择门店范围并查询。
4. 从名称下拉或结果列表选中商品和库位；完整 SKU 核对成功后返回标签页。
5. 核对并生成图片，保存 PNG 或分享至打印软件；已有打印服务时可使用系统打印。

标签沿用“库位打印”格式：80×60 毫米、945×709 像素、300 DPI 纯黑白。SKU 文字显示后六位，Code128 编码完整 SKU；空规格保留“规格：”。[标签格式示例（合成数据）](./kuguan-label-example.png)。

认证只保存在进程内，返回前台、登录失效或租户变化时重新核验；切换租户会清空原商品编辑内容。本版不自动上传商品、凭据或标签图片。登录和库存查询需要联网，不使用 Cloudflare 云端浏览器。

已通过自动化测试、Android release 编译、lint、条码校验及 APK 签名校验；本机新登录流程、隐藏页面后的查询和实际打印仍需手机实测。
