# 库管 Android

当前版本：[库管 0.5.0 APK](./kuguan-0.5.0.apk)，约139KB，Android 8及以上。已有0.2.0 / 0.3.0 / 0.4.0可直接覆盖安装，不要卸载或清除原应用数据。

## 新流程

1. 在App内登录牵牛花；验证成功后官方页面隐藏。
2. 打开“库位标签”，直接在顶部按名称、SKU、库位或更多条件查询，不再进入独立查询页。
3. 唯一记录自动选取；有多条结果时，从名称下拉或结果卡片选择商品与库位。
4. 核对完整SKU后，自动生成标签。商品名称、规格、SKU、库位和门店均来自查询结果，只读显示。
5. 保存图片、分享给标签打印软件，或使用手机系统打印。

界面调整为查询、只读商品资料、标签预览三部分；手机纵向排列，宽屏并排预览。查询条件改变就清除旧标签，旧的后台任务不能覆盖新结果。没有有效单一库位时，请先在牵牛花维护库位。

## 性能与大小

- 安装包由0.4.0的1,963,910字节降至138,691字节，约缩小93%；这不是整机运行内存降幅。
- 启用静态资源缓存、压缩查询脚本，按网页文档注入一次，减少空闲轮询。
- 登录与查询中快速检查，标签页空闲2.2秒、首页空闲10秒检查；仍执行登录核验。
- 隐藏页面不加载商品图片；退后台暂停网页计时器，后台60秒或低内存时释放网页。
- 标签在后台线程生成，RGB565位图约1.34MB；按行处理黑白像素，打印时按需解码，减少额外图片副本。

实际手机加载速度与进程RAM仍需实测，牵牛花WebView仍有运行时开销。本版不使用Cloudflare云端浏览器，不自动上传商品、密码、Cookie或标签图片。

标签尺寸保持80×60毫米、945×709像素、300DPI。条码包含完整SKU，文字显示后六位。长规格自动换行。商品源仍为“库存查询（新）”，不访问商品主档，不把商品条码当成SKU。
