# 库管 Android 0.5.1

[下载库管 0.5.1 APK](./kuguan-0.5.1.apk)，Android 8及以上。已有0.4.0或0.5.0可直接覆盖安装，不必卸载。

## 本次修复

- 查询界面合并为一个输入框，自动判断名称、SKU或库位；查询按钮移到查询卡片底部。
- 纯数字按SKU查询，A64-6-4和A64这类编码按库位查询，其余按商品名称查询。识别有歧义时可点击类型提示更改，仍使用同一个输入框；条码、外部编码也可切换查询。
- 查询和核对完整SKU时，牵牛花网页在原生界面后方继续渲染，保持隐藏。页面重绘暂时读不到租户时，显示原生验证提示并保留正在核对的记录；只有明确要求登录时才打开官方登录页。
- 同一租户验证恢复后继续原查询，选中商品后自动生成预览。唯一结果自动出图，多条结果先选商品与库位；资料全部只读。
- 仍需真实登录才能使用。验证未完成时阻止查询、导出，租户改变或明确退出时清除旧结果。

标签保持80×60毫米、945×709像素、300DPI，条码包含完整SKU，文字显示后六位。商品源为“库存查询（新）”。保质期功能继续暂停。

## 验证

已通过脚本与Java单元测试、release编译、lint和APK签名校验。Android模拟器使用受控合成页面，通过真实登录Activity、隐藏WebView、库存脚本和库位标签Activity完成SKU查询、名称结果选择、库位查询及自动预览；并特意在查询和切换流水时暂时隐藏租户信息，检查不会重新弹出登录。

这些测试没有连接真实牵牛花后台；实际店铺数据和手机仍需验收。
