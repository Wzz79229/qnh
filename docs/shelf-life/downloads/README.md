## 查询时保持库管界面

后台牵牛花网页设为完全透明，仍保留页面渲染，不能抢焦点、接管触摸或移到前台。移除了业务界面自动打开官方登录Activity的路径：查询遇到加载、SSO跳转或登录失效时只显示原生提示，由员工亲自点“重新登录牵牛花”才显示官方页面。首次启动仍必须登录牵牛花。

单个输入框自动识别名称、SKU、库位，查询按钮位于查询卡片底部；唯一结果自动选取，多条结果先选商品与库位，随后自动生成只读资料和标签预览。

## 得力DL-720W(NEW)蓝牙打印

1. 在手机系统蓝牙中配对打印机。
2. 生成标签后点击“打印”→“得力720W（蓝牙直打）”。
3. 允许库管连接附近设备，选择已配对的720W。
4. 核对80×60毫米标签纸、份数和纸张间隙，默认间隙2毫米，先打印1张。
5. 确认出纸定位、方向、文字和条码扫码正确后，再增加份数。

支持1–20份和0–5毫米间隙，记住选中的打印机和间隙。保留系统打印、保存PNG和分享。

按照[型号手册](https://tomro-res1-1316353155.cos.ap-guangzhou.myqcloud.com/common/90/b0b6cc6adb02f54a1681aaa4eaf041.pdf)（得力手册的经销商托管副本）使用经典蓝牙串口与TSPL指令。为打印机重新生成640×480黑白点阵，条码模块为整数像素，不直接缩放300DPI的导出PNG。无需得力云、Cloudflare打印服务或电脑中转。只读取已配对设备，不扫描周围设备、不请求定位。

**实体打印机尚未连接验证，需用你的720W试打确认兼容性和出纸效果。** “已发送”表示数据传输完成，未确认实体出纸；若发送中断或停止，应先检查是否已出纸再重试，App不会在发送数据后自动重打。
