# 库管 Android

当前版本：[库管 0.3.0 APK](./kuguan-0.3.0.apk)，Android 8 及以上。

## 安装

- 已安装鲜期 0.2.0：直接覆盖安装，使用同一签名及 applicationId，保留本机数据和牵牛花登录。
- 已安装最早的 0.1.0 验证版：其临时签名不同，需要先卸载再安装；0.1.0 尚未提供批次保存。
- 不要卸载或清除已有 0.2.0 的应用数据。保质期功能已按要求暂停，本版仅启用库位标签。

## 库位标签

1. 进入“库管”→“库位标签”。
2. 可直接填写商品名称、规格、完整 SKU 和一个库位，也可点击“从牵牛花库存查询（新）填入”。
3. 在手机内登录牵牛花，选择门店/仓并输入完整 SKU，从本次返回的库存记录中选择商品和库位。不再进入商品主档查询。
4. 核对并生成标签，保存 PNG，或分享给标签打印软件；手机已有打印服务时也可使用系统打印。

标签按原“库位打印”格式制作：80×60 毫米、945×709 像素、300 DPI、纯黑白。SKU 文字显示后六位，Code128 条码编码完整 SKU；空规格仍保留“规格：”一行。修改内容会使旧图片失效，避免导出旧数据。

[查看合成示例标签](./kuguan-label-example.png)。示例并非真实商品或真实库存。

本版图片在手机本地生成，不依赖 Cloudflare 或 GitHub 业务存储；不自动上传商品资料、账号凭据或标签图片。无需相机、相册、存储权限。牵牛花登录及库存查询需要联网。

已通过自动化测试、Android release 编译、lint、示例 PNG 全 SKU 条码解码和 APK 签名校验。手机上的新库存查询、图片保存/分享及实际打印仍需实机确认。

源码：[mobile-validation](https://github.com/Wzz79229/qnh/tree/main/apps/qnh-shelf-life/mobile-validation)。文件校验值见 [SHA256SUMS.txt](./SHA256SUMS.txt)。
